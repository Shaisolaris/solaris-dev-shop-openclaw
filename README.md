# Solaris Dev Shop for OpenClaw

MIT-licensed,61 specialist workflows plus one chief-of-staff coordinator. This native compatible-bundle marketplace references the complete source at an exact reviewed Git commit and adds zero new employee capabilities.

Install through OpenClaw's native plugin manager:

```sh
openclaw plugins install solaris-dev-shop --marketplace Shaisolaris/solaris-dev-shop-openclaw
```

Review the displayed source and declared skill surface before accepting the native installation prompt. Host tools, permissions and role prerequisites apply. There are no hooks, MCP servers, telemetry, credentials or auto-run processes. Local Python helpers need Python3.10+ and run only when explicitly invoked through host workflows. The publisher is Solaris Technologies, https://solaristek.com.

The underlying compatible bundle was tested on OpenClaw2026.10.5 using its real runtime inspection and skills registry. It contains all1196 canonical Solaris source files plus complete contained resources. Model behavior and production deployment are outside that test scope. Registry/curator approval is separate from this public source distribution.
